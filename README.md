
# Python LLM From Scratch

## Project Overview

Building a GPT-style Large Language Model from scratch using Python and PyTorch.

## Project Goals

- Understand Large Language Models.
- Implement text tokenization.
- Build a Bigram Language Model.
- Understand Neural Networks.
- Implement Self-Attention.
- Build Transformer Architecture.
- Train a GPT model.
- Develop a simple chatbot.

## Technologies

- Python 3.14
- PyTorch
- NumPy
- Matplotlib
- Jupyter Notebook
- Git and GitHub
- Google Colab

## Development Environment

- Operating System: Windows 11
- Code Editor: Visual Studio Code
- Python Environment: Virtual Environment (.venv)
